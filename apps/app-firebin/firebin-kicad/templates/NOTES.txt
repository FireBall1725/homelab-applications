Release:   {{ .Release.Name }}
Namespace: {{ .Release.Namespace }}
Image:     {{ .Values.image.repository }}:{{ .Values.image.tag }}

The MCP server talks to the FireBin API at:
  {{ .Values.configmap.config.data.FIREBIN_API_URL }}

Both tokens come from SealedSecrets in this chart:
  firebin-kicad-access-token  outbound fbin_pat_ (minted by the `mcp` FireBin user)
  firebin-kicad-token         inbound bearer that MCP clients must present on /mcp

Register it with an MCP client as:

  "firebin-prod": {
    "type": "http",
    "url": "https://{{ (index .Values.ingress.main.hosts 0).host }}/mcp",
    "headers": { "Authorization": "Bearer <firebin-kicad-token>" }
  }

Health check (no auth):
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "common.names.fullname" . }} 8090:8090
  curl http://localhost:8090/health
